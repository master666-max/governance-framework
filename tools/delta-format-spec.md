# Δ 差额格式规范 v1.0（20260920 WP-B 统一对账层格式定档）

> 跨库对账的唯一合法产出格式。任何自查、验收、第三方对账产出一律此格式。

## Δ 条目四件套（缺一即措辞）

```
声明 X    ← 件@blob:行 或 计数三元组（模式/路径域/命中类型）
工件 Y    ← 实算值 + blob@commit + 态标签（wt/blob）
复现命令  ← 可独立跑，不需作者上下文
差额      ← Y ≠ X 的量化差异 + 归口田块
```

## Δ 到期机制

| 字段 | 默认 | 说明 |
|---|---|---|
| deadline | 14 天（自 Δ 产生日起） | 到期未处置 → 自动升格呈报用户 |
| 升格条件 | overdue 旗标翻转 | 已升格的 Δ 不重复升格，但首次 overdue 时附原始 Δ 全文 |
| 处置态 | OPEN→ROUTED→CLOSED | 状态翻转须附归宿锚（commit 或工单引用） |

## Δ 产生来源（三种，格式同一）

1. 自查（主审计会话定期跑对账脚本）；
2. 外部对账器（qoder 式第三方投递）；
3. 跨圈制图时的跨库对账节（每圈 delta 报告强制含一节）。
