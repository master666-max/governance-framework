# index/ · 导出索引位（B 档注入面 · 中库模板骨架）

> 依据：《设计-四种落地形式》§三——中库相对微内核的差别之一=**工具与索引外置**：
> 支持"读文件式注入"（B 档：agent 开工时读一句话索引）与"库式注入"（`tools/kb.py query` 检索）双通道。

## 放什么（内容随用随长，结构随模板走）

| 建议件 | 内容 | 生成方式 |
|---|---|---|
| `一句话索引.md` | 每主题一行（"关于 X：见 E12/E47"）——agent 快速扫描用 | 由库运营者/宿主脚本从条目导出（生成器属分期项，见设计件 §七 D5） |
| `exp-*.md` | 长条目的展开版（B 档注入：需要细节时再读） | 手工或导出 |

## 纪律

- 本目录是**导出物**（可重建）——真相在 `kb.db` 的 events 账里；索引与账不一致时以账为准；
- 不进检索链（检索走 `kb.db`）；本目录只为"便宜地看一眼"服务。
