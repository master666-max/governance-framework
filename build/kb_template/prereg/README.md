# prereg/ · 判据注入位（中库模板骨架）

> 依据：SPEC §B-3（判据注入=宿主三件事之三）。本目录承载**本库自己的领域判据**——
> 先于实现的预注册件（判据冻结在实现之前，修改=新版本文件，不改本件）。
> 范例（完整形态）：`memsys/prereg/金标判据-v1.md`（irreversible 定义/阈值/ground truth 标法/接管判据）。

## 本库要写什么（按需，起步可空）

1. **severity_if_wrong 判例**：本库里哪些错判是"不可逆"（`irreversible`）、哪些是
   "可被下次纠正"（`redundant`）——决策留痕结构里的字段按此定义；
2. **晋升/退役阈值**（若与 `evo/tunables.py` 默认不同，写清差异与理由）；
3. **人工录入的零容忍面**（哪些条目来源=manual、错判一律升格）。

## 纪律

- 判据**先于**命中这些判据的代码/流程冻结；
- 每份判据件带版本号与生效日；改判据=新增文件（append-only 精神）；
- 中库体检（`conformance --kb`）会检查本目录**非空**（至少一份判据或本说明的替换件）。

## 机械格式（S8-5 · 20260923 起体检**强制**，缺项即 FAIL）

此前体检只查"目录非空"——判据件有没有版本、能不能被引用，一概不问，于是「有判据」与
「有个空目录」在输出上同形。现每份判据件（`prereg/*.md`，`README.md` 除外）必须能被机械抽出：

| 必检项 | 认的写法 | 例 |
|---|---|---|
| **版本行** | `版本：` / `版本:` / `version:` | `> 生效：2026-09-23。版本：v1。` |
| **生效日行** | `生效：` / `生效日期：` / `effective:` + ISO 8601 | 同上 |
| 引用锚（可选） | `判据锚：<id>` | `判据锚：kb-gold-v1` |

- 引用锚默认**机械派生** `<文件名>@<版本>`；件内自带 `判据锚：` 则以它为准（改名/移动而引用不断）；
- 多份合格件时，决策留痕的 `prereg` 指针取**字典序首份**（确定性）；
- 决策留痕（`memory_adjudicate`）的 `prereg` 字段=该锚；**无合格判据件时为 `null`**——
  读账即知"这条判定当时没有判据可依"；
- 实现：`gov/core/prereg.py`（库自带的治理核副本内）；负向对照：`build/tests/test_prereg_gate.py`。
